# Práctica Módulo 0: Consultas SQL en Python 📊

Este repositorio contiene la resolución de la primera práctica de Data Science. El objetivo del proyecto es demostrar el dominio de consultas SQL (selección, filtrado, agregación) utilizando una base de datos SQLite ejecutada directamente desde un entorno de Python.

## 🛠️ Tecnologías utilizadas
* Python 3
* SQLite3
* Pandas
* Google Colab

## 🚀 Cómo ejecutar este proyecto
Dado que el código está escrito en un Jupyter Notebook (`.ipynb`), la forma más sencilla de ejecutarlo y visualizar los resultados es a través de Google Colab.

1. Haz clic en el archivo `PracticaModulo0.ipynb` en este repositorio.
2. Si tienes la extensión o la opción habilitada, ábrelo directamente en **Google Colab**.
3. Ejecuta la primera celda de configuración para inicializar la base de datos y cargar los datos de prueba.
4. Ejecuta las celdas subsiguientes para ver el resultado de cada consulta SQL.

## 📌 Consultas realizadas
* **Selección Simple:** Listado alfabético de productos.
* **Filtrado Crítico:** Ventas específicas en Colombia mayores a $500.
* **Análisis de Rendimiento:** Ingresos totales agrupados por categoría.
* **Filtro de Élite:** Categorías que superan los $10,000 en ingresos.
